# Imbrication

A stacked fabric in which flat clasts lean consistently against one another, each tipped so its long axis dips upstream, recording the last event able to move the whole grain skeleton once the bed crossed [[Bioturbation|the reworking limit]]. Recovery of the fabric after a pause is set by the [[Paraconformity]] above it.
